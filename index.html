Coin Collector

How to play

Movement:

A = left, D = right, Space = kick

Rules

  1. Collect 20 coins to win.
  2. Avoid touching the bombs and obstacles.
  3. If lives = 0, game is over.
  4. Random difficulty will get assigned each game.
  5. There will be different obstacles on different difficulty.
